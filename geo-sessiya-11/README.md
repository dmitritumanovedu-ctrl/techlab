# Пробная сессия по географии · 11 класс

Тренировочное тестирование для подготовки к зимней сессии: 10 вариантов по 8 заданий (49 баллов, 90 минут),
по темам учебника (ед. обучения I–IV) и в формате БАК.

## Что внутри

| Файл | Зачем |
|---|---|
| `index.html` | страница ученика: тест с «закрытым экраном», таймером, разбором и PDF-бланком |
| `teacher.html` | страница учителя: печать бланков, баремов, шкалы отметок, ссылки на варианты |
| `js/config.js` | **настройки**: PIN учителя, время, число допустимых выходов, учебный год |
| `js/variants.js` | все 10 вариантов с ответами (можно править тексты) |
| `js/engine.js` | отображение и автоматическая проверка |
| `js/app.js` | логика страницы ученика |
| `css/style.css` | оформление и вид бланков для печати |

## Как опубликовать на GitHub Pages

1. **Поменяйте PIN.** Откройте `js/config.js` → `teacherPin: '2026'` → свой код.
   *Зачем:* этим PIN учитель разблокирует экран ученика и входит на страницу учителя.
2. **Загрузите папку в репозиторий.** На GitHub откройте репозиторий `techlab` → **Add file → Upload files** →
   перетащите всю папку `geo-sessiya-11` → **Commit changes**.
   *Зачем:* так тест станет частью вашего сайта TechLab.
3. **Подождите 1–2 минуты** и откройте:
   `https://dmitritumanovedu-ctrl.github.io/techlab/geo-sessiya-11/`
   *Зачем:* GitHub Pages сам обновляет сайт после каждого коммита (вкладка **Actions** показывает ход публикации).
4. **Страница учителя:** `.../geo-sessiya-11/teacher.html`.

## Как проходит тест

- Ученик вводит ФИ, класс, выбирает вариант (или случайный) → тест открывается во весь экран.
- Выход из окна/вкладки/полноэкранного режима = нарушение: экран закрывается, всё записывается в протокол.
  После 3 нарушений (настраивается) нужен PIN учителя.
- Ответы сохраняются в браузере: при случайной перезагрузке тест продолжается, таймер не останавливается.
- По окончании: автоматическая проверка, разбор с правильными ответами, самооценка развёрнутых ответов,
  кнопка «Скачать бланк ответов (PDF)» – ученик сдаёт этот файл.
- Ссылка `index.html?v=3` закрепляет вариант 3.

## Важно

- Результаты хранятся только на компьютере ученика – сдаётся PDF-бланк. (Позже можно подключить Firebase.)
- «Закрытый экран» – это защита для школьного класса, а не абсолютная: опытный ученик может найти PIN в коде страницы.
- Развёрнутые ответы (пункты «аргументируйте», «оцените») проверяет учитель; автоматически проверяются только короткие ответы.
- Статистика в задании 7 округлена – при желании сверьте с актуальными данными.
